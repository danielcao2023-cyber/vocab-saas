# 背单词 v3 功能与技术方案（草案）

> 撰写：Grok Bot，2026-10-17 上海时间。依据：仓库 `/workspace/vocab-saas/app` 分支 feat/curriculum-import、HEAD b4429a2 的代码，以及 方案-v2.md、v2/ 下文档。本文只是方案，没有改任何代码、Studio、服务或 wiki。
> 标记：【已核实】= 读代码确认；【推断】= 未实测；【待实测】= 需在 Studio 上试。

## 0. 现在已有什么【已核实】

一个用户、无登录。首页显示「今天：复习 N · 新词 N · 约 N 分钟」，可「开始复习 / 先学新词」。卡片有三种：**认词**（看英文→翻面看释义→自评 1–4 分）、**拼写**（看中文拼英文）、**听写**（听发音拼英文）；认词卡第一次学完，次日自动开出拼写和听写卡。三种卡各自独立用 FSRS 调度（ts-fsrs）。拼写/听写判对=Good、用提示=Hard、错=Again。评 Again 的词自动进**错词本**，页面可查看、手动移除、练错词（练的是认词卡，评分会改调度）。另有「进度」页（各词表已掌握数）。发音用**浏览器自带朗读**（Web Speech，en-US）。数据库里已预留但**没用上**的表：`word_content`（例句/助记）、`ai_jobs`、`ai_cache`、`content_feedback`；`words.unit`（单元）列存在但**为空**。目前没有任何 AI 调用、查词、家长页、打卡。

## 1. 六个功能

### 1.1 AI 讲解和例句
- **孩子看到**：认词卡翻面后、拼写/听写答完后，多一块「讲解」：常见搭配 2–3 个、中考风格例句 2 句（英文+中文）、易混词辨析（如有）。标「AI 生成 · 可能有误」，旁边「这条有问题」按钮。
- **数据/API**：用已有 `word_content`（kind = example / collocation / distinction），`status` 走 generated → approved；`GET /api/word/:id/content`。反馈写 `content_feedback`。
- **FSRS**：只是展示，不影响调度。
- **生成方式（建议：预生成+缓存，不现场生成）**

| | 现场生成 | 预生成并缓存（建议） |
|---|---|---|
| 等待 | 每次一次 codex 调用，【推断】十几秒到几十秒，孩子会卡住 | 打开即显示 |
| 额度 | 重复看同一词会重复消耗 | 1600 词各生成一次，可分批夜间跑 |
| 质量 | 来不及检查 | 可先抽查再放出 |

  做法：Studio 上一个后台脚本，逐批调用 `codex exec -m gpt-6-luna ... </dev/null`（每次显式带 `-m`，不改 ~/.codex/config.toml），要求输出固定 JSON，程序校验格式（例句必须含目标词、长度上限、无生僻词标记）后入库。按「孩子快学到的词」优先生成。批量跑的时间和速度需用户同意（占订阅额度）。
- **准确性**：提示词限定初中课标词汇和中考题型；入库前自动校验；**领域研究**抽查（每批随机约 5%，含全部人工释义词和多义词），重点核对辨析和搭配是否正确；**内容制作**不必参与（这里没有成片/口播）。孩子点「有问题」的条目自动隐藏待复核。
- **Codex/Luna 不可用时**：已生成的照常显示；没生成的显示「讲解还在准备」，背词完全不受影响（核心功能不依赖 AI）。后台任务失败记 `ai_jobs`，限次重试，不无限重跑。

### 1.2 更多题型：听音选义、看义选词、听写
- 听写**已经有了**【已核实】。新增两种选择题：
  - **听音选义**：只播发音，4 个中文释义选 1。
  - **看义选词**：给中文，4 个英文选 1。
  - 干扰项：先用同词性、词形相近的词（程序挑），以后可用 AI 生成的易混词。
- **FSRS 怎么算（建议）**：选择题比拼写容易，**不新建独立卡片**，而是作为**认词卡的一种出题方式**——认词卡到期时随机用「翻面自评 / 听音选义 / 看义选词」之一呈现。选对 = Good，选错 = Again（自动进错词本），省去孩子自评不准的问题。拼写、听写卡保持不变。这样不增加每日复习量。【推断】若希望选择题单独计算，需要新增卡片模式，每日量会明显增加，不建议。
- **数据/API**：`review_logs` 加 `qtype` 列（可空，旧记录为空），`/api/next` 返回题型和选项，`/api/review` 带回所选项由服务端判对。

### 1.3 错词本与重点复习
- 已有：自动收录、手动移除、练错词【已核实】。补的部分：
  - 错词按「错的次数 / 最近错」排序显示，标出哪种题型错的（拼写错 vs 认不出）。
  - 「练错词」改成混合题型，优先用这个词错过的题型。
  - 自动毕业：连续 3 个不同日子答对就移出（`correct_days` 字段已有，现规则需工程确认后定）。
- **FSRS**：练错词的评分照常写入 FSRS（现在就是如此）。建议当天对同一张卡的重复练习只让第一次计入调度，之后只记日志，避免把间隔推得过长或过短。

### 1.4 家长看板
- 单独页面 `/parent`，不在孩子导航里出现。内容：近 30 天每天学新词数/复习数、正确率、连续打卡天数、用时，错词 Top 20，课标进度（1095 / 505 分开）。只读。
- **要不要家长密码**：建议**不设**。理由：服务只在家里 Tailscale 内可达、本来就没登录；看板只读，不能改数据；孩子看到也无妨。如果你不希望孩子看到，可加一个简单 PIN（只是「隐藏」，不算真正的安全）。
- **数据**：全部从现有 `review_logs` 统计，不需新表；`GET /api/parent/summary`。

### 1.5 查词和按单元/词表浏览
- 顶部搜索框：输入英文或中文查词，显示释义、音标、发音、AI 讲解、学习状态（未学/学习中/已掌握）、是否在错词本。
- 浏览：按「三级核心词 / 二级词」、按首字母、按学习状态筛选。
- **按单元**：`unit` 列现在是空的，需要人教版九年级单元词表数据源——见问题 2。
- **FSRS**：查词不算复习，不改调度。可提供「加入错词本」按钮。

### 1.6 激励：打卡与连续天数
- 当天完成「今日任务」（复习清零 + 新词学完）即打卡；首页显示连续天数、日历小格子；7/30/100 天等里程碑徽章。
- 断签容忍：建议每月 1–2 张「补签卡」（避免一次生病就前功尽弃）——需你决定。
- **数据**：新表 `daily_stats(day, new_count, review_count, correct, completed)`，可由 `review_logs` 回算，旧数据补出历史打卡。不加积分、排行、抽奖等。

## 2. 发音
- 现在：浏览器自带朗读（Web Speech API, en-US，语速 0.9）【已核实】。音质和可用声音取决于设备和浏览器【推断】；没声音时页面会提示。
- 听音选义和听写都**依赖发音质量**。建议第 1 期仍用浏览器朗读（零成本），用户实际试听；若不满意，第 2 期在 Studio 上用 macOS `say` 预生成 1600 个音频文件存本地【待实测音质】，也可考虑有授权的真人发音源（需另查授权，不默认）。
- 例句朗读同样先用浏览器朗读。

## 3. 分期

| 期 | 内容 | 粗估规模（Codex 写码） |
|---|---|---|
| 1 | 题型（听音选义、看义选词并入认词卡）、错词本增强、家长看板、打卡连续天数 | 约 2–3 天；不依赖 AI |
| 2 | 查词与浏览；AI 讲解/例句流水线（先生成孩子未来 2 周要学的约 200 词并抽查） | 约 3–4 天 + 抽查时间 |
| 3 | AI 全量补齐 1600 词、AI 易混词做干扰项、本地音频（如需）、按单元浏览（如有数据） | 约 2–3 天，取决于数据和额度 |

【推断】规模按以往 M1/M2 节奏估计，未实测。

**依赖**：第 2 期需 Codex + gpt-6-luna 在 Studio 上可用（`-m gpt-6-luna` 调用需先试通【待实测】）；按单元需数据源；本地音频需试听。
**风险**：
- 改动正式库：只做加列/加表，每期上线前一次性备份 vocab.db，保留旧版本目录便于回滚；孩子已有学习记录不得变化（上线前后核对 cards/review_logs 计数）。
- AI 内容出错：校验 + 抽查 + 反馈隐藏。
- 订阅额度/限流：分批跑，失败不影响背词。
- 题型变化让孩子不适应：可在设置里关掉选择题。

## 4. 验收标准
**第 1 期**
- 用正式库副本测试：迁移后原有卡片数、review_logs 数、每张卡的到期日完全不变。
- 认词卡到期时三种呈现方式都会出现；选对记 Good、选错记 Again 并进错词本；每日复习量与上线前相同。
- 干扰项不与正确答案同义、不重复。
- 家长页数字与数据库手工统计一致（抽 3 天核对）；孩子导航里没有家长入口。
- 打卡：完成今日任务后连续天数 +1，跨上海午夜正确；历史打卡可回算。
- 在用户真实设备上实际点过（Air 需关小火箭）。

**第 2 期**
- 查词：英文/中文都能查到，1600 词全覆盖；查词不产生 review_logs。
- AI：抽查样本错误率 ≤ 约 2%（领域研究出抽查表）；格式校验 100% 通过才入库；断开 Codex 时页面正常、显示「还在准备」。
- 全程只用 `-m gpt-6-luna`，~/.codex/config.toml 未改（比对哈希）。

**第 3 期**
- 1600 词 AI 内容覆盖率与抽查结果报告；音频（如做）全部可播放、用户试听认可；按单元（如做）与教材核对 2 个单元。

## 5. 需要你决定的问题
1. AI 批量生成可以在什么时间跑（如每天夜里 1–6 点）、每天最多多少词？会占 ChatGPT 订阅额度。
2. 要不要按「九年级教材单元」浏览？要的话，需要你提供或认可一个单元词表来源（教材版本，如人教版）。
3. 家长看板要不要加一个简单 PIN 不让孩子看到？（默认不加）
4. 打卡要不要补签卡（每月 1–2 张）？
5. 选择题并入认词卡（不增加每日量）——你同意这种算法吗？
