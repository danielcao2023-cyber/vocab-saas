# 词库缺项持续补齐实施计划

**目标：** 为新增词书的缺项逐步补齐可信讲解、适合的发音拼写对照和可核实的真人录音，直至全库缺项处理完毕；无法获得适合录音的短语或占位符保持明确待处理。

**范围：** 基于公共种子与当前已发布资源去重，以词条 ID 共享各词书内容；先按人教高中必修一 Unit 2 开始，后续继续其余高中册次和考试词书。单音节、短语和专名不直接套用多音节拆分规则。

**质量边界：** 本地 Claude Code CLI + coder 仅起草，不直接写应用；音标、主要释义、用法、构词和录音先核实来源，再经 Codex 核查。结构通过不等于语言正确。来源不明的真人录音不入库，合成发音不冒充真人。

## 步骤

- [x] 从 `app/mobile-public/offline/seed.db`、`app/data/lessons/`、`app/data/pronunciation/manifest.json` 和 `web/src/content/sound-spelling/` 按词 ID 和词书生成覆盖清单，记录唯一词条与各单元交集；重复词不重复入库。
- [ ] 对下一单元建立词头、教材释义、IPA 与词类的事实包；针对词典有缺项、冲突、专名、含占位符的词条单列核查。使用公开词典作为证据，保留来源和校对记录。
- [ ] 分批让本地 Coder 输出受限结构的例句、翻译和用法，临时产物放仓库外。对每条逐词复核、修正错误、拒绝不可验证的条目；符合 `validateLesson` 后才生成 reviewed 文件。
- [ ] 针对适合学习的单词制作按音值对应字母的对照；核对重音、连读及音标变体，避免推断历史词根。沿用现有对照的结构与交互。
- [ ] 按词条查找可核实作者和许可的真人整词/整段录音，保存原始 URL、许可、摘要，验证媒体可解码；尊重来源限流，失败记为未知。针对音变、口音和同音录音显示说明。
- [ ] 为确有错误的基础释义或音标写入 `app/data/vocabulary/corrections.json`，使用精确旧值和来源保护；增加目录版本以触发本地与离线端备份后升级，不覆盖个人记录。
- [ ] 编写覆盖测试，运行相应测试、全量测试、网页与离线构建；在独立测试库验证 UI 和音频，不向个人学习库写入验收记录。校对发布资源和许可清单，更新覆盖清单与批次审计。
- [ ] 完成且验证的批次提交在功能分支；保留未完成词条和录音清单，继续下一批，直至全范围完成。安卓版需单独重新打包验收。

2026-10-27 进度：Unit 2 已发布 6 份讲解及 38 份录音；另 15 份草稿完成第一轮修订，待证据核对及拼写对照后才能发布。全目标仍有 11453 份讲解及 11428 条真人录音待补（按唯一词条统计）。
