# 多词库与人教高中单元实施计划

> 按用户已确认的范围直接实施；Coder 负责边界明确的代码任务，Codex 审核内容与集成。

**目标：** 接入人教2019版高中7册及考研、四六级、托福、雅思、GRE；设置一次选一本词书，可限定高中册次/单元；所有词条移除助记和补充讲解两块。

**架构：** 单词保留稳定 ID，词书、单元、成员使用独立关系表，同词跨词书共享证据。词库数据以带版本与来源的只读清单导入，重复导入不修改学习记录。默认继续初中课标1600词。切换学习范围不删除已有答题、到期和提示记录。网页与离线运行时使用相同服务逻辑。

**全局约束：** 不修改下载源文件；不覆盖原1600词已审核释义；不平均切分教材单元；不宣称导入释义是完整人工审核讲解；不读取或打包个人学习记录/旧模型配置；未明确要求合并、推送或重打APK。

## 核验重点

1. 一词多书只建一套认词/拼写/听写证据；大小写或合并词头存在歧义时显式映射，不能仅按 casefold 合并。
2. 官方教材词表中实际列出的 Unit 归属优先于社区文件；每册覆盖必须完整，不能将无 Unit 的词塞进任意单元。
3. 切书不能清空当天日志或把旧题判为新题；每日不同词总量继续由全局目标约束。
4. 设置失败必须保存原请求重试，离线持久化失败不得假成功或丢失学习数据。
5. 删除的是所有学习页面的两个展示功能，历史内容文件不做破坏性删除。
