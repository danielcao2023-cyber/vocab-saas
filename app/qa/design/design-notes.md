## 1. 方向
「纸和墨」：暖白纸色背景、深墨色文字、一种主色（墨蓝）加一种点缀色（琥珀，只给打卡用）。安静、耐看、不幼稚，适合一个初三学生每天用、用一整年。
- 单词用衬线大字（像词典），界面文字用系统黑体，两种字体分工清楚。
- 一屏只做一件事：学习时只有进度条和一张卡，没有导航干扰。
- 连续天数按 `内容.md` 的原则**不放大**：首页只在右侧小卡和顶栏小标签里出现；徽章只有 7/30/100 三个，没有积分、排行、宝箱。
- 颜色有固定含义：绿 = 对/掌握，红 = 错，琥珀 = 打卡，墨蓝 = 可以点的主操作。

## 3. 字体（只用系统字体，不引用任何外部 CDN 或网络字体）
- 界面：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`
- 单词/英文选项：`"New York", ui-serif, "Iowan Old Style", Georgia, "Noto Serif", serif`（Mac/iPhone 上是 New York 或 Iowan，Windows 上是 Georgia）。
- 数字统一 `font-variant-numeric: tabular-nums`，计数变化时不跳动。
- 字号：单词 56px（手机 44px）；释义 18px；正文 15px；辅助 13px；最小 11px（只用于星期和坐标轴）。
- 注：截图是在 Linux 盒子上用 Chrome 渲染的，中文是 Noto Sans CJK、英文衬线是 Noto Serif。在用户的 Mac/iPhone 上会换成苹方和 New York，字形更细一点，布局不变。

## 4. 版式
- 桌面：内容最宽 1040px；首页左右两栏（左：今天 + 课标进度 + 错词本；右：打卡日历和徽章）。学习页卡片最宽 680px，居中。
- 手机（≤640px）：单栏；顶部导航收进**底部标签栏**（今日 / 错词本 / 进度）；选择题选项改为一列；卡片高度至少占屏幕 64%，评分按钮落在拇指能够到的下方。
- 圆角 16px（卡片）/ 12px（按钮）；阴影很浅（`0 1px 2px` + `0 8px 24px`，6% 透明度）。
- 家长页 `/parent` 用自己的顶栏（“学习看板 · 家长 · 只读”），没有孩子的导航；孩子页面也没有指向它的链接。

## 5. 动效原则
- **短、轻、有意义**：只用来说明“换了一张卡”“答案对不对”，不做庆祝动画、礼花、抖动。
- 换卡：新卡淡入并上移 8px，280ms，`cubic-bezier(.2,.7,.2,1)`。
- 翻面：释义区淡入 200ms（不做 3D 翻转，避免晕和看不清）。
- 选择题：选中后 150ms 内正确项变绿、选错项变红，其余变淡；**答错不抖动**（不带惩罚感）。
- 按钮按下缩放到 0.98；进度条宽度过渡 300ms。
- 打卡完成：日历当天格子从描边变为填充，200ms；没有弹窗。
- 系统开启“减少动态效果”（`prefers-reduced-motion: reduce`）时全部关闭。截图就是在这个模式下拍的。

## 6. 可访问性和键盘
- 所有快捷键沿用现状并统一：空格 听发音、→/Enter 翻面、1–4 自评或选项、R 重听、Tab 提示首字母、Enter 提交/下一个、Esc 暂停、? 快捷键表。选择题选项同时标 A–D 和 1–4。
- 键盘焦点用 4px 浅墨蓝光圈（`box-shadow: 0 0 0 4px var(--primary-soft)` + 主色边框），不能去掉 outline 不补。
- 点击区域不小于 44×44px（手机）。
- 状态不只靠颜色：对/错都有文字。

- **词源 vs 联想**：
  - 「词源」：实线墨蓝浅底框，深蓝实心标签“词源”，下面列同根词（标出哪些是课标词）。只有核实过、置信度高的内容才放这里。

- **近义/反义** 用词条小卡片：英文 + 中文 + 状态（“已学”绿色 / “课标外”灰色）。课标词和已学过的词排前面。
