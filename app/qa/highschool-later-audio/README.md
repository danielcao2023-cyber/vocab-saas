# 必修一后续单元录音批次

从 Unit 3 至 Unit 5 的缺录音词条中，按单词原形检索 Commons 的美式或英式真人录音。`batch-1.json` 记录本批 67 份录音的词条、来源、作者、许可、口音及文件摘要。发布前检查文件名与目标词严格匹配、来源及许可可验证、音频可解码且哈希一致；未经音质逐条人工听辨，异读或词形可能引起歧义的候选列入 deferred，未接入。

网页与离线版均核对了全部 67 条播放信息，并通过页面按钮抽测 5 条完整播放。独立测试库用于验证，不包含个人学习数据。英语口音标签只描述录音口音，不代表词汇在某地区的使用范围。
