# 必修一后续单元录音批次

从 Unit 3 至 Unit 5 的缺录音词条中，按单词原形检索 Commons 的美式或英式真人录音。`batch-1.json` 记录本批 67 份录音的词条、来源、作者、许可、口音及文件摘要。发布前检查文件名与目标词严格匹配、来源及许可可验证、音频可解码且哈希一致；未经音质逐条人工听辨，异读或词形可能引起歧义的候选列入 deferred，未接入。

网页与离线版均核对了全部 67 条播放信息，并通过页面按钮抽测 5 条完整播放。独立测试库用于验证，不包含个人学习数据。英语口音标签只描述录音口音，不代表词汇在某地区的使用范围。

`batch-2.json` 为必修二第一至第五单元筛出的 119 份录音，采用相同来源和文件检查；异读、词形及地名指代等待确认候选继续留在 deferred。来源与可解码检查并不等于逐份人工听辨。

`batch-3.json` 为必修三第一至第五单元筛出的 122 份录音。存在词性异读、口音来源不清、词形或地名指代疑问的候选暂缓接入；保留对应来源和文件的核验信息。

`batch-4.json` 为选择性必修一筛出的 129 份录音；共用词条沿用已有录音。异读、变化词形及口音证据不足的候选暂缓接入，本批来源及解码检查不代表逐份人工听辨。

`batch-5.json` 为选择性必修二筛出的 116 份录音，按实际来源标记口音；文件名与描述明确冲突、存在异读或词形疑点的候选暂缓。来源、许可和解码已核对，未逐份人工听辨。

`batch-6.json` 为选择性必修三筛出的 111 份录音；存在词性异读、口音差异或词形疑点的候选暂缓。已检查来源、许可和解码，未逐份人工听辨。
