## 行为与边界

- 每日最多40个不同词条，复习和未完成项优先；重复补测不占新名额。没有接触过的已排计划词仍显示为新词。
- 独立答对一次即可结束当天；求助先记一次 Again，填对仅记纠正，不再使用 Hard。最近完整答案/讲解暴露后5分钟内不算独立回忆。
- 一词一天最多追加2次独立补测；到上限仍不会，保留次日复核。没有可做的题时可回首页，不阻塞倒计时。
- 首次/失败后有次日复核；延迟记住必须距前次该能力尝试与最近同词答案暴露均至少24小时，跨午夜不自动算延迟成功。
- 拼写优先用于同级同到期的决策，不压过更早到期听写；缺证据超过3个上海自然日的能力按最久未尝试轮换。已验证且未来到期的卡不被三日线强拉出。
- 三型分别保存FSRS与证据。重点须由发生困难的能力在其后2个不同日期、实际间隔满足24小时的成功解除。“长期较稳”另要求三型有延迟证据、两种拼写卡间隔至少7日等条件；它不是考试认证。
- 5分钟、2次、3日、首遇汉译英、保持率0.90均为本轮试用参数；没有宣称长期教学效果已验证。

## 数据与恢复

`learning_events`是追加事件；每题最多一次probe，客户端不能自报rating/due/stage。`cards`仍是每型唯一FSRS，v3通过现有review适配写入，纠正不调度、也不推进旧错词毕业。旧写API被409保护；旧枚举仅为兼容投影。

Node启动先库外verifiedBackup，再DDL/事务激活；只读预览已核验源SHA及邻接文件不变。明确帮助/错误导入失败，无法证实的旧正确不伪造延迟成功。孤立旧日志保留原间隔并等待验证。原日志/result_json不改写；原card/词/日计划/日统计投影保存在迁移快照。历史日期的打卡统计不因重算被抹除。

Android专用 `files/learning-pre-v3.db`：固定路径、文件锁、临时写与fsync、原子rename、目录同步、大小和SHA256回读；同内容重试可用，冲突拒绝覆盖。备份不占普通a/b轮换槽。IndexedDB用独立 `learning-pre-v3` 键。加载旧库→验证备份→内存迁移→新快照确认→开放应用；失败不回退种子。sql.js先复制输入字节，避免迁移改掉调用方保留的原快照。待确认操作会封锁其他操作，重试沿用同一请求/事件编号。

恢复只在隔离副本演练。不能把降级安装旧APK当作安全回滚；正式恢复前须复制当前数据，并知悉迁移后新进度会被恢复点替换。不要直接删除原数据或备份。
